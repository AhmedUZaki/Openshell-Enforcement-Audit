    Protected folder
    
Creates a folder with wide-open Linux permissions (chmod 777), then lets OpenShell's own policy decide what's actually allowed there -- so any blocking you see is OpenShell's, never Linux's. Note: this recreates the selected sandbox from scratch with the new policy (Landlock can't grant new access to an already-running sandbox), so anything else in it is lost.
